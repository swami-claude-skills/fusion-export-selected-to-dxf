Released: Oct 30, 2026

**Export Selected DXF v1.0.0**: first build.

- **Export selected sketches.** One DXF per selected sketch or set of sketch curves, from a dark dockable panel with a live selection count.
- **Real units setting.** Exports in design units, mm, cm, m, in or ft, with the correct unit header in the file.
- **Options.** Output folder, file naming, overwrite or auto-number, construction geometry, sketch points, projected geometry and flat-pattern bend lines, all remembered between sessions.
