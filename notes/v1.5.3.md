Released: Nov 1, 2026

**Export Selected to DXF v1.5.3**: update check runs every time the panel opens.

- **Update check on every open.** Before, the add-in checked for a newer version only the first time its panel opened after Fusion started, so a release that came out later wasn't offered until Fusion restarted. It now checks each time the panel opens (at most once every two minutes), and asks GitHub for a fresh copy of the version file instead of a cached one.

**Download:** ExportSelectedToDXF.zip below, or click **install update** in the panel.
