**Export Selected to DXF v1.3.0**: updates install themselves.

- **Install update button.** When a newer version is out, the green banner in the panel offers **install update**. The add-in downloads the new version from GitHub, backs up the current one, and replaces its own files. Then Shift+S ▸ ExportSelectedToDXF ▸ Stop ▸ Run, or restart Fusion. No installer, so nothing to approve in macOS Settings.
- **New install method.** Unzip, then in Fusion press Shift+S, click **+** next to My Add-Ins, choose the ExportSelectedToDXF folder, tick Run on Startup, and click Run. The double-click installers are still in the zip as an alternative.
